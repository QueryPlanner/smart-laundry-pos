Updating? Run the new installer over the old one. Your data is kept.

macOS and Linux builds are unsigned: on macOS, right-click the app and choose Open the first time. Linux: sudo apt install ./Smart-Laundry-POS-linux-amd64.deb. The macOS build is for Apple silicon Macs only.
